# PIC32CZ wolfHSM port stub

Compile-only stub of the PIC32CZ wolfHSM port, used by CI to build
`config/examples/pic32cz-wolfHSM.config` without the real port
(`make WOLFHSM_MICROCHIP_PIC32CZ=tools/ci/pic32cz-wolfhsm-stub`). The result is
not a runnable bootloader.

The wolfBoot/wolfHSM port for PIC32CZ is distributed as part of the wolfHSM
PIC32CZ platform release bundle, which is under NDA. For access or more
information, contact [facts@wolfssl.com](mailto:facts@wolfssl.com).
